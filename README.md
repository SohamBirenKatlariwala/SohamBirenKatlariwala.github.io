# Soham Biren Katlariwala – academic homepage

Single-page site in the style of Jon Barron's academic template.

## Add your photo
Save a square photo as `images/profile.jpg`. Until then the page shows "SK" initials.

## Publish on GitHub Pages
1. Create a public repository named `SohamBirenKatlariwala.github.io` on your GitHub account.
2. Upload `index.html`, `README.md` and the `images/` folder.
3. In the repository, open Settings → Pages and set Source to the `main` branch, root folder.
4. After a minute the site is live at https://sohambirenkatlariwala.github.io/

## Updating
Edit `index.html`: news items are in the `News` list, papers in `Publications`.
